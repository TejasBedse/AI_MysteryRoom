# AI Pipeline

Prompt version `blueprint-v1` establishes truth before evidence. A single structured Gemini response contains the complete blueprint, private solution and player-facing evidence generated from those established facts. The private solution includes one evidence explanation per item and one explanation for each alternative suspect. The prompt requests exactly three suspects, six evidence items and a short timeline while remaining within the product's 3–5 suspect and 6–10 evidence ranges. The official Google GenAI SDK is used server-side with JSON-schema response mode; Zod validates the returned object. The configured primary model is tried first; transient provider failures and timeouts fall back to a separately configured model. Schema failures receive one bounded correction attempt with field paths only, then the fallback model is tried. A deterministic validator checks known IDs, unique IDs, valid timestamps, chronological order, at least three essential clues, and complete clue and alternative-suspect explanations. No invalid case is published. If generation fails, the case is marked failed with a safe diagnostic message.

The final reveal is assembled deterministically from the stored private solution and actual evidence; it does not ask a new model to decide the culprit. Image/video generation is disabled and not implied by this implementation.
